## 🚀 Selected Projects

### 🩺 GastroCare — Doctor Appointment System

A Spring Boot application for a solo doctor's **online and in-person appointments**, with a patient booking flow and a protected doctor workspace.

- Implemented phone verification, appointment cancellation and doctor schedule management.
- Prevented double booking through an atomic database update.
- Added real-time availability updates using WebSocket / STOMP.
- Used Flyway migrations, automated tests, OpenAPI documentation and Docker Compose.

**Stack:** Java · Spring Boot · Spring Security · Spring Data JPA · PostgreSQL · Flyway · WebSocket · Docker

[Explore the repository →](https://github.com/Proggertopper/doctor-appointment-system)

### 🛒 eCommerce — Microservices Backend

A learning project exploring an online store backend with separate product, user, order and notification services.

- Used Spring Cloud Config, Eureka and an API Gateway.
- Integrated Keycloak for authentication and API security.
- Worked with Kafka order events and Redis rate limiting.
- Added Docker Compose, Kubernetes manifests, tests and GitHub Actions CI.

**Stack:** Java · Spring Boot · Spring Cloud · Keycloak · Kafka · Redis · PostgreSQL · MongoDB · Docker

[Explore the repository →](https://github.com/Proggertopper/eCommerceApplication)
