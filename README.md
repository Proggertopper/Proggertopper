## Live Projects

### [PropertyCost — Real Estate Analysis Platform](https://mypropertycost.com/)

A live full-stack web platform that helps homebuyers and real-estate investors evaluate property decisions.

* Built 11 calculators for rent vs. buy, cash flow, IRR, ownership cost, renovation ROI, and other investment metrics.
* Implemented account-based saved calculations, scenario stress testing, deal comparison, portfolio summaries, PDF reports, and credit-based product flows.
* Deployed and operated the application as a public product with authentication, PostgreSQL-backed data storage, Redis sessions, Nginx, Docker, Cloudflare, and HTTPS.
* The source code is private because this is an actively deployed product. I am happy to discuss the architecture and implementation decisions.
